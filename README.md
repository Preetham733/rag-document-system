# 📄 RAG Document System

Upload any PDF and ask questions about it using AI.

## ✨ Features
- 📁 Upload any PDF document
- 🔍 AI reads and understands your document
- 💬 Ask questions in plain English
- 🤖 Answers based only on your document

## 🔗 Live Demo
[Click here to view the app](https://rag-document-system-pd7utmdceszjt6ihekdcpc.streamlit.app/)

## 🛠️ Tech Stack
- Python, Streamlit
- ChromaDB — Vector database
- Sentence Transformers — Text embeddings
- Groq API (Llama 3.3) — AI answers

## 🚀 Run Locally
pip install -r requirements.txt
streamlit run app.py
